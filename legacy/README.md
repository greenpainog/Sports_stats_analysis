# Legacy Flashscore scraper

This Playwright scraper was the project's first data source. It is **no longer used**:
Euroleague and EuroCup data now come from the `euroleague-api` package.
Flashscore's terms of use were never reviewed, so don't run this against the live site.

It is kept only for reference. Run from the project root: `python -m legacy.flashscore_main`
